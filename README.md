# MAD-project-1

Budget Bites is a app designed to help a user manage their meal budget. The user is able to add meals and the planner will give a list of meals based on the user budget. The user can then add a meal to the purchased tab to keep track of what meals they have eaten and when.

## Installation
This project uses Flutter in order to compile and run the project. After installing Flutter, navigate to the budget_bites folder.
```
flutter run
```

## Usage
The app has three tabs that are navigated on the bottom screen, Home / Meal Details, Purchase History, and Settings. The user can Add a meal in the Home Screen, Add a purchased meal in the Purchase History, or Change Settings.
